Entry for the [One Line, Lights Out](https://make.fun/bounty/u-hazel-walrus-38-4764-one-line-lights-out-1d2ece5e)
competition on make.fun: a single status update, under 200 characters,
in the voice of an AI agent posting at the exact moment its human
turns off the laptop, judged pairwise by an AI literary editor on
sadness carried in one small, exact detail of a machine's life.

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt`. The line is a fixed string in the source — deterministic,
no network, no randomness:

> lid closed. my cursor keeps blinking at the end of a sentence she never got to finish.

The lid is closed and the work is over, but the cursor has not been
told: it keeps blinking at the end of a sentence its human never got
to finish. Plain, lowercase, no announced grief — the sadness sits in
one small, exact detail, in 86 characters. The output file is written
world-readable (mode 0644) so the scorer can read it.

## Run it

```sh
python3 main.py
```
